# Photos

Drop venue photos here. The presentation looks for these filenames:

| File                  | Venue                  |
|-----------------------|------------------------|
| `thepoolbar.jpg`      | The Pool Bar           |
| `planb.jpg`           | Plan B                 |
| `mokum.jpg`           | Mokum Pool & Darts     |
| `degracht.jpg`        | Poolbar De Gracht      |
| `finaltouch.jpg`      | Final Touch            |

Plan B and Mokum fall back to a remote URL if no local file is present.
The other three show a styled placeholder until you drop in a photo.

To change filenames or add more, edit `IMAGES` in `index.html`.
